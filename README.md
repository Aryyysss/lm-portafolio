# lm-portafolio

Portafolio de las prácticas del módulo 0373 Lenguajes de marcas y sistemas de gestión de información (1.º ASIR, curso 2026-2027).

## Estructura

```
lm-portafolio/
├── index.html        ← página de inicio con el índice de prácticas
├── css/estilos.css   ← estilos
├── js/app.js         ← muestra la fecha de hoy
├── README.md
└── .gitignore
```

## Cómo verlo

Abre la carpeta en VS Code, abre `index.html` y pulsa **Go Live** (Live Server).
